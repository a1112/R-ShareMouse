USB / 有线连接

可使用已建立的 USB 网络共享或 USB 以太网。通过该网卡的主机 IP 打开接收链接，并核对上方实际连接地址；必要时关闭 Wi‑Fi，确保视频走有线连接。RTT 是网络往返时间，不是屏幕显示延迟。

iPad 普通数据线直连尚不支持。USB 热点依赖蜂窝版 iPad、运营商支持及 Windows Apple 驱动；Wi‑Fi 版 iPad 可使用兼容的以太网适配器接入局域网。

当前入口复用实验性移动网关的 HTTP 配对，仅用于受信任局域网；WebRTC 视频本身加密。画面触摸使用 Windows 原生触摸注入，不会注册硬件触摸屏。
